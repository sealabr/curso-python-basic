# Aulas de Python

## Introducao

Este repositorio foi criado para estudos e praticas de Python.
Aqui voce encontra exemplos simples para acompanhar as aulas e exercitar os conceitos basicos da linguagem.

## Instalacao do Python (Windows)

1. Acesse o site oficial: [python.org/downloads](https://www.python.org/downloads/)
2. Clique em **Download Python** para baixar a versao mais recente.
3. Execute o instalador baixado.
4. Marque a opcao **Add Python to PATH**.
5. Clique em **Install Now** e aguarde a instalacao concluir.

## Verificando a instalacao

Abra o terminal (PowerShell ou Prompt de Comando) e execute:

```bash
python --version
```

Se o comando exibir a versao instalada, o Python foi configurado corretamente.

## (Opcional) Verificando o pip

O `pip` e o gerenciador de pacotes do Python. Para verificar:

```bash
pip --version
```

Se aparecer a versao do `pip`, esta tudo pronto para comecar os estudos.
