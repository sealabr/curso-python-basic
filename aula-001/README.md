# Aula 001 - Primeiros passos com Python

Este diretorio contem exemplos basicos para iniciar em Python.

## Arquivos da aula

- `00-hello-world.py`: primeiro programa
- `01-teste.py`: entrada de dados com `input`
- `02-logica.py`: exemplos simples de logica
- `03-funcoes.py`: exemplos basicos de funcoes

## Como rodar no VS Code

1. Abra o VS Code.
2. Clique em **File > Open Folder** e selecione a pasta `aulas`.
3. No explorador de arquivos do VS Code, entre em `aula-001`.
4. Abra o arquivo que deseja executar, por exemplo `00-hello-world.py`.
5. Abra o terminal integrado em **Terminal > New Terminal**.
6. No terminal, execute:

```bash
python aula-001/00-hello-world.py
```

Para rodar outros arquivos, troque o nome no comando. Exemplo:

```bash
python aula-001/01-teste.py
```

## Dica

Se o comando `python` nao funcionar, tente:

```bash
py aula-001/00-hello-world.py
```
